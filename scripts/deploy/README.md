# Скрипты развертывания и диагностики StockForecast

В этой папке лежат два универсальных bash-скрипта для обслуживания проекта на любом сервере (Ubuntu/Debian, Nginx/OpenLiteSpeed, с любым пользователем и путями).

## Быстрый старт

### 1. Скрипт восстановления (restore_stockforecast.sh)

**Когда использовать:** после переустановки сервера, переезда на новый хостинг или полного сбоя.

**Что делает:**
- Клонирует репозиторий из GitHub.
- Создает config.php (если его нет).
- Настраивает права доступа для веб-сервера.
- Выравнивает кодировку MySQL.
- Проверяет настройки слушателя OpenLiteSpeed (если используется).
- Настраивает Cron-задачи.
- Генерирует начальные кэши (Скринер, Точность, Сигналы).
- Перезапускает веб-сервер.

**Как запустить:**

```bash
# Скачать скрипт с GitHub и сразу выполнить (одной командой)
sudo bash <(curl -s https://raw.githubusercontent.com/CAPITALOV/StockForecast-by-KAPITALOV/main/scripts/deploy/restore_stockforecast.sh)
