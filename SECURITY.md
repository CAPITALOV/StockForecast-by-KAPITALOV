## Supported Versions

We actively maintain and provide security updates for the following versions of StockForecast:

| Version  | Supported          |
|----------|--------------------|
| 2.2.x    | :white_check_mark: |
| < 2.2.0  | :x:                |

The current release is **v2.2.0** — see [Releases](https://github.com/CAPITALOV/StockForecast-by-KAPITALOV/releases).
Patch releases within `2.2.x` (e.g., `2.2.1`, `2.2.2`) inherit support from `2.2.0`.
