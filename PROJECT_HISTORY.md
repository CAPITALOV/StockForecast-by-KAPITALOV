# StockForecast — История проекта и руководство по поддержке

## 1. Общее описание
**StockForecast** (by KAPITALOV) — это аналитическая платформа для прогнозирования трендов акций и верификации прогнозов. 
Проект построен на PHP (роутинг, бэкенд) + MySQL + Lightweight Charts (фронтенд).
Версия на момент документа: **1.19.0**.

## 2. Основной стек и структура
- **Бэкенд:** PHP 7.4+, MySQL 5.7+, PDO.
- **Фронтенд:** HTML5, CSS3 (переменные для тем), Vanilla JS, Lightweight Charts v4.1.0.
- **Интеграции:** MOEX ISS API, Yahoo Finance (через FreeNewsApi.ai и Stooq), Telegram Bot API, RSS (ПРАЙМ, Банки.ру).

### Ключевые директории:
- `lib/` — бизнес-логика (API, индикаторы, верификация, новости).
- `pages/` — HTML-шаблоны (лендинг, график, точность, админка).
- `cron/` — фоновые задачи (авто-загрузка истории, проверка попаданий).
- `data/` — кэши (JSON). **Важно: права 775, владелец = PHP-процесс.**

## 3. Ключевые вехи и внедренные фичи
1. **Базовый каркас (v1.0):** Загрузка прогнозов (3 линии), парсер TXT/CSV, кэширование истории в `history_bars`.
2. **Верификация (v1.2):** Пересчёт `delta` в цену через cumprod, расчет MAPE и Hit-rate. Статусы: сбылся / частично / не сбылся.
3. **Графики (v1.3–v1.6):** Левая ось (цена), правая (дельта). RSI (14), SMA, EMA, уровни перекупленности.
4. **Screener (v1.17):** Сводная таблица точности по всем тикерам с фильтрами и экспортом.
5. **Новости (v1.18):** Yahoo Finance для US, RSS ПРАЙМ/Банки.ру для MOEX. Кэш 15 минут.
6. **Свечи и OHLC (v1.19):** Переход на полноценные OHLC-данные. Переключатель «Линии / Свечи» в админке и на сайте.

## 4. Критические баги, которые были исправлены
- **504 Gateway Time-out:** В `lib/api.php` были таймауты Yahoo 425с и Stooq 2500с. Исправлено на 10с и 15с. В бэкфилл добавлен `set_time_limit(55)` и `LIMIT 1`.
- **Верификация пропадала при смене графика:** Исправлено полным пересозданием графиков (`destroyCharts()`) перед каждым рендером.
- **Повреждение Git (corrupt loose object):** Локальный `.git` был пересобран с нуля клонированием с GitHub.
