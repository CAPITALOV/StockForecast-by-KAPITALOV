# Changelog

Все значимые изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/),
версии — [SemVer](https://semver.org/).

## [2.2.0] - 2026-10-25
### Added
- Страница «История сигналов» (Бэктест доходности).
- Индикатор «Ширина рынка» (Market Breadth) на главной.
- Функционал «Избранное» (Watchlist) на базе localStorage.
- Тултипы с уверенностью для сигналов на графике.
- Фильтр по сигналам в Скринере.

### Fixed
- **Критический фикс**: Устранены зависания сервера (504) на страницах Скринера и Точности благодаря переходу на JSON-кэширование.
- Исправлен расчет `Hit-rate` (ранее показывал фейковые 100%).
- Исправлен конфликт кодировок MySQL (`collation`).
- Исправлен SQL-запрос в Бэктесте (использование колонки `ts` вместо `date`).

## [2.1.0] - 2026-10-24
### Added
- **Адаптивная Линия 2 (Synthetic)**: Заменено простое среднее на адаптивную математическую модель (SMA-5, Z-score, адаптивные веса).
- **Торговые сигналы (Buy/Sell)**: На график Линии 2 в amCharts добавлены маркеры (зеленые/красные) в точках разворота тренда.
- **База данных**: Добавлена таблица `synthetic_components` для кэширования расчетов.
- **Cron-скрипт**: `scripts/cron/refresh_synthetic.php` для ежедневного пересчета компонентов.
- **Библиотека**: `lib/synthetic.php` — ядро математических расчетов.

### Changed
- API `api-forecast` теперь отдает сигналы `buy`/`sell` для Линии 2.
- Обновлен `pages/stock.php` (интеграция сигналов в график).

## [2.0.0] — 2026-10-24
### 🚀Крупный релиз: векторная верификация, баннер-светофор, фикс истории
#### Добавлено
- **Баннер-светофор** на странице тикера: 🟢 Покупать / 🟡 Ждать / 🔴 Не покупать (логика на основе `delta_trend`).
- **Фильтр по MA200**: сигнал «Покупать» блокируется, если SPY (US) или IMOEX (MOEX) ниже MA200 (A/B-тест: PF 1.28 → 1.53).
- **Плашка «Историческая точность»** для 8 золотых тикеров (C, RTX, T, IBM, ZTS, KO, PLZL, ALRS).
- **`bin/audit_lines.php`** — CLI-аудит всех тикеров (Money Metrics, PnL, CSV).
- **Тренд дельты** в таблице верификации: ↑ синий / ↓ красный.
- **Столбец «Цена закрытия»** и «Факт. изменение» в детальной таблице.

#### Изменено
- **`history_get()`** теперь корректно учитывает `$days` (история 20 лет вместо 1 года).
- **`verify_forecast()`** переведён на векторную верификацию (сравнение `delta` с `actual_return`).
- **Период по умолчанию** на странице тикера: 5 лет (было 1 год).

#### Исправлено
- **`history_get()` игнорировал `$days`** — API всегда возвращал ~257 баров.
- **Fatal `Cannot redeclare average_forecast_lines()`** — конфликт библиотек.
- **`parse_forecast()` не парсил пробел** — линии не рисовались.
