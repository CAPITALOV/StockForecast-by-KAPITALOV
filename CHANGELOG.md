## [2.0.0] — 2026-10-24

### 🚀 Крупный релиз: векторная верификация, баннер-светофор, фикс истории

#### Добавлено
- **Баннер-светофор** на странице тикера: 🟢 Покупать / 🟡 Ждать / 🔴 Не покупать
  - Логика на основе `delta_trend` (тренд дельты, не знак дельты)
  - Паттерн разворота: «первая ↑ после 2+ дней ↓»
- **Фильтр по MA200**: сигнал «Покупать» блокируется, если SPY (US) или IMOEX (MOEX) ниже MA200.
  - По A/B-тесту: **PF 1.28 → 1.53** на 9 «золотых» тикерах 2021–2026.
- **Плашка «Историческая точность»** для 8 золотых тикеров (C, RTX, T, IBM, ZTS, KO, PLZL, ALRS):
  - Показывает win% / PF / n / exp для конкретного тикера
  - Для US-тикеров сигнал берётся с RPO, для MOEX — с Delta Close
- **`bin/audit_lines.php`** — CLI-аудит всех тикеров:
  - Money Metrics (PF, Exp, WinRate)
  - PnL per-ticker в CSV
  - Параметры: `--market`, `--top`, `--min-count`, `--csv`, `--tickers`
- **Тренд дельты** в таблице верификации: ↑ синий (ускорение) / ↓ красный (замедление)
- **Столбец «Цена закрытия»** и «Факт. изменение» в детальной таблице
- **Голубая подсветка будущих дат** с ожидаемым направлением стрелки
- **Значок «✔ проверенный»** у тикеров с `|Pearson| > 0.05`
- **Line 2 (Synthetic)** стала публичной — видна гостям

#### Изменено
- **`history_get()`** теперь корректно учитывает `$days` — история 20 лет вместо 1 года
  - Бэкфилл через `mode='live'` теперь **сохраняет** данные в БД (раньше только в `auto`)
  - При `mode='auto'` — мерж DB + live с дедупликацией
- **`verify_forecast()`** переведён на **векторную** верификацию:
  - Сравнивает `delta` с `actual_return`, а не компаундинг цены с ценой
  - Pearson между delta и фактическим движением (не между ценами — убрали спуриозную корреляцию 0.88)
  - Новые поля: `expected_dir`, `delta_trend`, `delta_change`, `actual_return`, `vector_dev`, `avg_vector_dev`
- **`api-verify`** использует `verify_all_lines()` — Line 2 вычисляется на лету, если её нет в БД
- **Сводная таблица «Сравнение линий»** — убраны Money Metrics (PnL одинаковый у всех линий, вводил в заблуждение)
- **Период по умолчанию** на странице тикера: 5 лет (было 1 год)

#### Исправлено
- **`history_get()` игнорировал `$days`** — API всегда возвращал ~257 баров (1 год) вместо запрошенного периода. График «20 лет» показывал 1 год.
- **Fatal `Cannot redeclare average_forecast_lines()`** — конфликт между `lib/forecast.php` и `lib/indicators.php`. Обёрнуто в `if (!function_exists())`.
- **`parse_forecast()` не парсил пробел** — формат `2020-03-18 0.64966` не читался, линии не рисовались.
- **Дубль в `verify_all_lines`** — Line 2 отсутствовала в `api-verify` для админа (проверялось `$num === 2` вместо `public`).
- **«Ближайший разворот»** показывал даты из 2020 года из-за пропусков в истории.

#### Удалено
- Компаундинг цены из дельт (`$current_forecast_price`) — вызывал спуриозные ошибки 35–80%
- Money Metrics из UI на странице тикера (осталось только в `bin/audit_lines.php`)

#### Миграции БД
**Нет.** Все изменения — на уровне PHP/JS. Работает на существующей схеме `forecast_lines`, `history_bars`, `stock_map`.

#### Breaking changes
- Формат ответа `api-verify` расширен (новые поля), но старые сохранены — обратная совместимость.
- `history_get()` возвращает больше данных — если где-то был хардкод «не более 730 дней», код надо пересмотреть.

#### Известные ограничения
- **Line 2 (Synthetic)** = простое среднее `avg(Line1, Line3)`. Не адаптивный синтез.
- **Модели long-only** — на 40 000 точек истории отрицательных дельт было 25 (0.06%). Модель сигналит только рост.
- **Модель — индикатор импульса, не прогноз цены.** На 100 000 точках: PF 1.09, WinRate 50.7%, Pearson 0.004–0.008 (статистически нулевой).
- **Токсичные тикеры** (Pearson < −0.05): GOOGL, AAPL, BNB-USD, TSLA, INTC, CRM, SONY — модель на них ошибается систематически. В UI пока не блокируются.

#### Исследование
За релиз проведено:
- Бэкфилл 101 тикера за 20 лет (`history_bars`: 100 000+ баров)
- Аудит 100 019 точек верификации на 85 тикерах
- 7 гипотез проверено (magnitude, reversal, MA200-фильтр, RPO vs Delta, и др.)
- Найдено 8 «золотых» тикеров с историческим edge (PF > 1.2)
- A/B-тест MA200-фильтра: **+0.25 PF** (статистически значимо, 5σ)

## [1.24.0] — 2026-10-23
### Добавлено
- **Визуальные маркеры верификации:** На график «Сравнение моделей» добавлены цветные точки статусов (зеленые — успех, красные — убыток, оранжевые — частично). Будущие даты (ожидается) скрыты для чистоты графика.
- **Колонка «Дельта» в таблице верификации:** Теперь в таблице отображаются исходные значения дельты из базы, рядом с прогнозной и фактической ценой.
- **Исправлена синхронизация дат:** Даты из API прогнозов и API верификации теперь нормализуются без учета часовых поясов, что гарантирует 100% совпадение маркеров и табличных данных.

## [1.19.0] — 2026-10-20

### Добавлено
- **Японские свечи (OHLC)**: на странице тикера появился переключатель
  «Линии / Свечи».
  - База данных теперь хранит `open`, `high`, `low`, `close` в таблице
    `history_bars` (миграция в `bootstrap.php`).
  - Провайдеры MOEX ISS и Yahoo Finance переведены на загрузку OHLC.
  - Для старых записей без OHLC работает fallback на `close`.
- **Настройки отображения в админке**: добавлен роут `admin-settings`
  и таблица `settings`. Администратор может задать тип графика
  по умолчанию (Линии или Свечи).
- **Пользовательский выбор**: клиент может переопределить тип графика
  на странице тикера. Выбор сохраняется в `localStorage`.

### Исправлено
- **Пропадала верификация при смене типа графика**: графики теперь полностью
  пересоздаются (`destroyCharts()`), сбрасываются все серии, а
  `loadVerification()` вызывается после полной отрисовки. Это решило проблему
  с исчезновением таблицы верификации при переключении Линии ↔ Свечи.
