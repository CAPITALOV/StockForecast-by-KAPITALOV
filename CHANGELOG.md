# Changelog

Все значимые изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/),
версии — [SemVer](https://semver.org/).

## [1.21.0] — 2026-10-23

### Добавлено
- **Основной график на amCharts 5 Stock Chart** (`pages/stock.php`):
  - свечи и линии цены, прогнозные линии, MA (SMA/EMA) и Bollinger Bands —
    на `am5stock.StockPanel`;
  - сглаживание линий `tension: 0.8` (максимально плавно), включая линию цены;
  - **SVG-рендер для периодов ≤ 365 дней** (чёткий вектор, экспорт SVG),
    **canvas для длинных периодов** (5–20 лет) — автоматический выбор по `days`;
  - встроенные тултипы amCharts, встроенная легенда, встроенный экспорт PNG
    основного графика (`am5plugins_exporting`);
  - `value_type: delta` — правая ось, `price` — левая.
- **Смена темы**: при переключении темы сайта amCharts-график пересоздаётся
  с `am5themes_Dark` / `Animated`.
- Cache-bust `style.css?v=3`.

### Исправлено
- **Экспорт PNG на amCharts 5**: плагин подключается как
  `https://cdn.amcharts.com/lib/5/plugins/exporting.js`, объекты —
  `am5plugins_exporting.Exporting` / `am5plugins_exporting.ExportingMenu`
  (а не `am5.exporting.*`, из-за чего падало
  `Cannot read properties of undefined (reading 'Exporting')`).

### Известные ограничения (POC)
- Нижняя панель RSI/MACD и блок «Сравнение моделей» пока на `lightweight-charts`;
  синхронизация зума между amCharts и нижней панелью отсутствует (Этап 2).
- Экспорт PNG сохраняет только основной график (без нижней панели).
- amCharts 5 Stock Chart используется по linkware-лицензии — на графике
  видна атрибуция amCharts.

## [1.20.1] — 2026-10-20

### Исправлено
- **Скрытие заголовка RSI**: кнопка «📊 Панель» на странице тикера теперь
  скрывает `<div class="rsi-head">` вместе с графиком и легендой во всех
  Chromium-браузерах, включая Яндекс.Браузер. Причина — устаревший CSS
  в кэше; решено через `style.css?v=2` и правило
  `body.hide-lower .rsi-head { display: none; }`.
- **`applyOptions` на скрытых панелях**: `toggle-lower` и `window.resize`
  больше не вызывают `applyOptions` при `clientWidth === 0` — исчезли
  ошибки в консоли при скрытии панели и ресайзе.

## [1.20.0] — 2026-10-20

### Добавлено
- **Страница архива новостей** (`?r=news`): на главной теперь висят только
  3 последних анонса, а полный список с картинками доступен на отдельной странице.
- **Загрузка картинок к анонсам**: в админке появилось поле для прикрепления
  изображения (JPG, PNG, WebP, GIF). Файлы сохраняются в `static/uploads/`.
- **Telegram-уведомления при публикации**: при создании новой новости
  в админке бот автоматически отправляет сообщение в канал со ссылкой на сайт.
- Миграция БД: в таблицу `announcements` добавлена колонка `image`.
- Создана папка `static/uploads/` с `.gitignore` для защиты репозитория от мусора.

### Исправлено
- Восстановлен полный код API-роутов в `index.php` после случайной замены
  на заглушки (исправлена ошибка `Unexpected end of JSON input` на графиках).

## [1.19.0] — 2026-10-20

### Добавлено
- **Японские свечи (OHLC)**: на странице тикера появился переключатель
  «Линии / Свечи».
  - База данных теперь хранит `open`, `high`, `low`, `close` в таблице
    `history_bars` (миграция в `bootstrap.php`).
  - Провайдеры MOEX ISS и Yahoo Finance переведены на загрузку OHLC.
  - Для старых записей без OHLC работает fallback на `close`.
- **Настройки отображения в админке**: добавлен роут `admin-settings`
  и таблица `settings`. Администратор может задать тип графика
  по умолчанию (Линии или Свечи).
- **Пользовательский выбор**: клиент может переопределить тип графика
  на странице тикера. Выбор сохраняется в `localStorage`.

### Исправлено
- **Пропадала верификация при смене типа графика**: графики теперь полностью
  пересоздаются (`destroyCharts()`), сбрасываются все серии, а
  `loadVerification()` вызывается после полной отрисовки. Это решило проблему
  с исчезновением таблицы верификации при переключении Линии ↔ Свечи.
