# Changelog

Все значимые изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/),
версии — [SemVer](https://semver.org/).

## [1.20.1] — 2026-10-20

### Исправлено
- **Скрытие заголовка RSI**: кнопка «📊 Панель» на странице тикера теперь
  скрывает `<div class="rsi-head">` вместе с графиком и легендой во всех
  Chromium-браузерах, включая Яндекс.Браузер. Причина — устаревший CSS в кэше;
  решено через `style.css?v=2` и правило `body.hide-lower .rsi-head { display: none; }`.
- **`applyOptions` на скрытых панелях**: `toggle-lower` и `window.resize`
  больше не вызывают `applyOptions` при `clientWidth === 0` — исчезли
  ошибки в консоли при скрытии панели и ресайзе.

## [1.20.0] — 2026-10-20

### Добавлено
- **Страница архива новостей** (`?r=news`): на главной теперь висят только 3 последних анонса, а полный список с картинками доступен на отдельной странице.
- **Загрузка картинок к анонсам**: в админке появилось поле для прикрепления изображения (JPG, PNG, WebP, GIF). Файлы сохраняются в `static/uploads/`.
- **Telegram-уведомления при публикации**: при создании новой новости в админке бот автоматически отправляет сообщение в канал со ссылкой на сайт.
- Миграция БД: в таблицу `announcements` добавлена колонка `image`.
- Создана папка `static/uploads/` с `.gitignore` для защиты репозитория от мусора.

### Исправлено
- Восстановлен полный код API-роутов в `index.php` после случайной замены на заглушки (исправлена ошибка `Unexpected end of JSON input` на графиках).

## [1.19.0] — 2026-10-20

### Добавлено
- **Японские свечи (OHLC)**: на странице тикера появился переключатель «Линии / Свечи».
  - База данных теперь хранит `open`, `high`, `low`, `close` в таблице `history_bars` (миграция в `bootstrap.php`).
  - Провайдеры MOEX ISS и Yahoo Finance переведены на загрузку OHLC.
  - Для старых записей без OHLC работает fallback на `close`.
- **Настройки отображения в админке**: добавлен роут `admin-settings` и таблица `settings`. Администратор может задать тип графика по умолчанию (Линии или Свечи).
- **Пользовательский выбор**: клиент может переопределить тип графика на странице тикера. Выбор сохраняется в `localStorage`.

### Исправлено
- **Пропадала верификация при смене типа графика**: графики теперь полностью пересоздаются (`destroyCharts()`), сбрасываются все серии, а `loadVerification()` вызывается после полной отрисовки. Это решило проблему с исчезновением таблицы верификации при переключении Линии ↔ Свечи.
