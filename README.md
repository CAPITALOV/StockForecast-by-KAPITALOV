# StockForecast

Прогнозы и верификация акций MOEX и US. PHP + MySQL.
Три независимые линии прогноза на каждый тикер, автоматическая верификация
с фактической историей цен (до 20 лет), расчёт точности (MAPE, hit-rate),
screener, сравнение тикеров, экспорт CSV и PNG, RSI, MACD, Bollinger Bands,
скользящие средние (SMA/EMA), фоновые задачи (Cron) и Telegram-уведомления.
Рад, что всё получилось! Проект действительно получился масштабным и законченным. 🎉
Если подвести краткий итог, теперь у вас есть:
Работающий сайт с графиками, индикаторами (RSI, MACD, Bollinger) и тремя линиями прогноза.
Автоматическая верификация прогнозов с расчётом точности (MAPE, hit-rate).
Screener для быстрой оценки, кто из тикеров угадывает лучше всех.
Фоновые задачи (Cron) для авто-загрузки истории за 20 лет и проверки попаданий.
Telegram-уведомления о сбывшихся прогнозах.
Экспорт данных в CSV и графиков в PNG.
Чистый и понятный код на GitHub с полной документацией.
Это отличный фундамент. Если в будущем захочется развивать проект (добавить новые индикаторы, сделать API для внешних сервисов, настроить более сложные алерты или углубиться в анализ данных) — возвращайтесь, я всегда на связи.

## 📋 Требования

- PHP 7.4+ с расширениями `pdo_mysql`, `mbstring`
- MySQL 5.7+ / MariaDB 10.3+
- Исходящие HTTP-запросы к `iss.moex.com`, `query1.finance.yahoo.com`, `stooq.com`
- Для Cron: доступ к CLI (запуск `php` из консоли)

## 🚀 Быстрый старт

```bash
# 1. Клонировать
git clone git@github.com:CAPITALOV/StockForecast.git
cd StockForecast

# 2. Настроить БД
cp config.example.php config.php
# отредактировать config.php (DB_HOST, DB_NAME, DB_USER, DB_PASS)

# 3. Создать папку для кэша
mkdir -p data
chmod 775 data

# 4. Открыть в браузере: http://ваш-домен/index.php
# 5. Зайти в ?r=admin-login (admin / admin) и сменить пароль
