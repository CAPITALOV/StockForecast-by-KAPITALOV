# StockForecast

Прогнозы и верификация акций MOEX и US. PHP + MySQL.
Три независимые линии прогноза на каждый тикер, автоматическая верификация
с фактической историей цен (до 20 лет), расчёт точности (MAPE, hit-rate),
screener, сравнение тикеров, экспорт CSV и PNG, RSI, MACD, Bollinger Bands,
скользящие средние (SMA/EMA), фоновые задачи (Cron) и Telegram-уведомления.

Прогнозы · Верификация · Точность
Прогнозы акций
и их честная верификация
Три независимые линии прогноза на каждый тикер. Автоматическое сравнение с фактической историей цен MOEX ISS и Yahoo Finance. Прозрачный расчёт точности — без «подгонки» задним числом.
то внутри
Полный цикл: от загрузки CSV из Yii до графика с отклонением по каждой точке.
01
Три линии прогноза
До трёх независимых прогнозов на тикер (цена или дельта). Разные модели, одна шкала времени.
02
Импорт из Yii
CSV Id, StockId, Date, Delta автоматически разложится по тикерам через справочник.
03
MOEX + US
Официальный ISS API Мосбиржи и Yahoo Finance (со Stooq-фолбэком) — без ключей.
04
Фиксация истории
Котировки кэшируются в history_bars — верификация не зависит от источника.
05
Верификация
Сравнение прогноза с фактом: отклонение в %, статус «сбылся / частично / не сбылся».
06
Метрики точности
MAPE и hit-rate по тикеру, бирже и линии. Экспорт в CSV. Сравнение нескольких тикеров.
Как это работает
Четыре шага — от CSV до отчёта по точности.
Загрузите справочник
CSV cap_stock.csv из Yii строит маппинг StockId → тикер.
Загрузите прогнозы
CSV раскладывается по тикерам на 1–3 линии.
Откройте график
Цена + линии прогноза, RSI, детализация день/неделя/месяц.
Смотрите верификацию
По каждой точке — прогноз, факт, отклонение и статус. CSV на экспорт.
Акции
Выберите биржу и тикер — увидите график, прогнозы и верификацию.

## 📋 Требования

- PHP 7.4+ с расширениями `pdo_mysql`, `mbstring`
- MySQL 5.7+ / MariaDB 10.3+
- Исходящие HTTP-запросы к `iss.moex.com`, `query1.finance.yahoo.com`, `stooq.com`
- Для Cron: доступ к CLI (запуск `php` из консоли)

## 🚀 Быстрый старт

```bash
