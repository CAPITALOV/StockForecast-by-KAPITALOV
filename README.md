# StockForecast (by KAPITALOV)

Аналитическая платформа для прогнозирования движения акций, индексов и эмитентов. Проект построен на PHP (бэкенд) и amCharts 5 (фронтенд).

Система публикует прогнозные линии (дельты), автоматически сопоставляет их с фактической историей цен (до 20 лет с MOEX ISS и Yahoo Finance) и показывает прозрачную верификацию без «подгонки задним числом». 

## 📈 Что умеет система

- **Векторный анализ (Правило 50%):** Система прогнозирует не только цену, но и направление движения (дельту). Верификация считает прогноз успешным, если рынок пошел в нужную сторону и прошел хотя бы 50% от прогнозного хода.
- **Корреляция Пирсона:** Для каждой линии прогноза рассчитывается математическая связь между прогнозной дельтой и фактической ценой закрытия.
- **Визуальные маркеры статусов:** На графике сравнения моделей точки окрашиваются в зависимости от статуса: зеленые (сбылся), красные (не сбылся), оранжевые (частично).
- **Двухосевой график:** Сырые значения дельт (левая ось) наложены на реальную цену закрытия (правая ось) — видно, как прогноз соотносится с реальным трендом.
- **Плавный фронтенд на amCharts 5:** Линии сглажены (`tension: 0.8`). Автоматический выбор рендера: четкий SVG для периодов до 1 года и производительный Canvas для длинных периодов.
- **Нативные индикаторы:** RSI(14) и MACD отрисовываются встроенными средствами amCharts с полной синхронизацией зума и курсора с основным графиком.
- **Современный UI:** Единый шрифт Inter (self-hosted), монохромные SVG-иконки и ровные цифры (`tabular-nums`) для таблиц.
- **Инструменты аналитика:** Свечи и линии, Bollinger Bands, скользящие средние (SMA/EMA), Screener (сводная таблица точности), сравнение нескольких тикеров, экспорт в CSV и PNG.

## 🛠 Требования

- PHP 7.4+ с расширениями `pdo_mysql`, `mbstring`, `curl`, `fileinfo`
- MySQL 5.7+ / MariaDB 10.3+
- Исходящие HTTP-запросы к `iss.moex.com`, `query1.finance.yahoo.com`, `stooq.com`
- Для Cron: доступ к CLI

## 🚀 Быстрый старт

1. Клонировать репозиторий:
   `git clone git@github.com:CAPITALOV/StockForecast-by-KAPITALOV.git`
2. Перейти в папку и скопировать конфиг:
   `cd StockForecast`
   `cp config.example.php config.php`
3. Отредактировать `config.php` (DB_HOST, DB_NAME, DB_USER, DB_PASS).
4. Запустить миграции БД:
   `php bootstrap.php`
5. Выставить права на кэши и загрузки:
   `mkdir -p data static/uploads`
   `chmod 775 data static/uploads`
6. Открыть в браузере: `http://forecast.sotis.org/index.php`
